🧠 Ingat!

Pola titik selalu punya aturan tetap: bisa bertambah sama banyak (+2, +2, +2, …) atau bertambah makin banyak (+2, +3, +4, …). Temukan aturannya, dan kamu bisa menebak gambar ke-10, ke-100, bahkan kapan pun!

MATERI 3

Menghitung Korek Api 🔥

Persegi-persegi ini disusun dari korek api. Perhatikan korek api berwarna merah muda — itulah tambahan untuk persegi yang baru!

1 persegi

🧠 Rumus pintar: banyak korek api = 3 × banyak persegi + 1

🎮 Tantangan

Berapa korek api yang dibutuhkan untuk 6 persegi berjejer?

👀 Amati Baik-Baik!

Persegi pertama butuh 4 korek api. Setiap persegi baru hanya butuh 3 korek api, karena satu sisi sudah dipakai bersama persegi di sebelahnya! Itulah sebabnya polanya melompat: 4 → 7 → 10 → 13 → 16 …

KESIMPULAN 📝

Apa yang Kita Pelajari Hari Ini?

🔁 Pola berulang — temukan unit pola yang diulang, lalu lanjutkan urutannya. Contoh: 🔵🔺🟢, 🔵🔺🟢, 🔵🔺🟢 …
⚪ Pola jumlah titik — cari aturan bertambah atau berkurangnya (+2, +3, …) untuk menebak gambar berikutnya tanpa menghitung dari awal.
🔥 Korek api persegi berjejer — persegi pertama 4 korek api, tiap persegi baru +3. Rumus pintar: 3 × banyak persegi + 1.
🔺 Menghitung segitiga — hitung yang kecil dulu satu per satu, baru yang gabungan (2 kecil, 4 kecil, seluruhnya). Gambar C tadi ada 8 segitiga!
🧱 Pola tumbuh — bintang bertambah 2 (1, 3, 5, 7 …), tangga kubus bertambah 2, 3, 4, 5 (1, 3, 6, 10, 15 …).
🌍 Pola di sekitar kita — batik, ubin, kalender, jadwal, dan lagu semuanya berpola. Matematika membantu kita menebak dengan cerdas, bukan menebak sembarangan!
